# WordVault 前端 URL 参数一览

> 一句话版：`?style=A|B|C` 选整体风格（默认 A）、`?bright=low|mid|high` 选亮度档（**默认 low**）、
> `?sat=low|high` 微调气体饱和度、`?poster=P1|P2|P3` 打开星芒（**默认关闭**）。
>
> 早期还有一个 `?off=glow|stars|dust` 的分层测量开关（开发期用来把星点 / 辉光 / 背景
> 三层贡献分开量），**已移除**。

| 参数 | 取值 | 默认 | 影响什么 |
| --- | --- | --- | --- |
| `style` | `A` / `B` / `C` | **A** | 整体风格：辉光强度与扩散、星尘数量、背景渐变色、L0 标签预算、调色板饱和度。A=银河感优先，B=干净星点优先，C=星云气感优先 |
| `bright` | `low` / `mid` / `high` | **low** | 亮度档：同时改「星点增益、背景中心/边缘色、星尘亮度、辉光倍率」四组（定义在 `src/three/style.ts`） |
| `sat` | `low` / `high` | 跟随风格 | 只改星云气体的饱和度（low=0.42 保守、high=0.55 激进），白核不变 |
| `poster` | `P1` / `P2` / `P3` | **不带 = 关闭** | 只给每团最亮的 1% 加十字星芒（星核给到 13px 绝对尺寸）。P1 星芒最强、P2 最弱；**三个档目前只在星芒强度上不同** |
| `l0` | `A` / `B` / `C` / `D` | **A** | **实验性**：L0 全景的四种渲染策略（见下）。默认 A 就是当前线上观感 |
| `thin` | `0` | 不带 = 开启抽稀 | **仅用于同机位对比**：`?thin=0` 关掉 L0 抽稀。正常使用不要带 |

### L0 的四种策略（`?l0=`）

用户反馈过「星星太小、辨识度不够、太密集」。这一组是为了**比较**而做的，默认是 A。

| 值 | 做法 | 保留独立星点 |
| --- | --- | --- |
| **A**（默认） | 尺寸下限 3px + 按投影密度确定性抽稀 | 9,000 / 26,608 |
| B | 只渲染「重要词」为独立星（亮核），其余只留辉光 | 640 |
| C | 星团内按子类拉成缕状（旋臂感） | 11,030 |
| D | 只渲染视角中心附近的团，外围降为光晕（近实远虚） | 2,555 |

**四方案都不删词**：被排除的星只是不作为独立星点渲染，**仍参与辉光层**，
团的大小/亮度仍由全部词决定（「每个星空容纳所有词」没有被破坏）。

**用户 2026-10 看过四张对比截图后选了「保持现状」，即 A。** B/C/D 保留在代码里备查。

补充说明：
- 上面这些都不影响功能（搜索、词条、关系连线、复习、统计、自评），只是渲染参数；
- 参数定义集中在 `src/three/style.ts` 一个文件里，改数值不需要动渲染代码；
- 默认（不带任何参数）就是**当前线上观感**：`style=A` + `bright=low` + **无星芒**。
