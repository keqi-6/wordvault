# 词穹 WordVault · 需求基线

- 版本：v1.0
- 生成日期：2026-09-28
- 来源：与本项目所有者的 82 题结构化问答（逐题确认）
- 效力：本文件是该项目的需求基线。项目所有者当前指令 > 本文件 > 代码事实。

---

## 0. 一句话定义

**一个给自己用的、可分享给同学的网页版六级词汇关系词典：每个单词是一颗星，词与词之间的关系分三层绑定，复习表现直接反映为星光亮度。**

---

## 1. 定位与边界

| 项 | 结论 |
|---|---|
| 产品定位 | 以六级为第一个数据集，**产品定位通用**（架构上不锁死六级） |
| 是不是「AI Agent」 | 不是。主体是词典/背单词应用 + 星空可视化，**核心学习闭环不依赖 LLM**；LLM 只作可选辅助入口 |
| 使用者 | **自己用为主，会分享给同学/朋友**；不做账号体系，但别人能打开来用 |
| 平台 | 网页（浏览器） |
| 运行形态 | 前端 + 本地小后端；**全走 SQLite + API** |
| 分享形式 | 整个仓库 + 一键启动脚本 |
| 节奏 | 每周固定投入 5-10 小时，长期推进 |

### 怎么算做成

**项目所有者自己真的用它背完了六级词。**

| 六级真题语料 | YinsinSirius/CET6-Resources | `codeload` tar.gz HTTP 200，整库约 1.06 GB，含扫描件 | 例句、真题高频词表、微型题 |
| 星空坐标（词向量） | GloVe 6B `glove.6B.zip` 862,182,613 B；备选 fastText `crawl-300d-2M.vec.zip` 1,523,785,255 B | HTTP 200 | 布局 |

### 数据源的缺口（必须承认）

| 维度 | 开源数据 | 决定 |
|---|---|---|
| 词形 | ECDICT `exchange` + `lemma.en.txt` | 有 |
| 声音 | ECDICT `phonetic` + CMUdict + 浏览器 TTS | 有 |
| 当前义项 | ECDICT `translation` / `definition` | 有 |
| 搭配 / 词块 | KyleBing `phrases`（覆盖不全） | 有，但不完整 |
| 语法行为 | **无开源数据** | 模型生成 + 标注「机器生成」 |
| 语域与语用 | **无开源数据** | 模型生成 + 标注「机器生成」 |
| 概念与指代 | **无开源数据**（WordNet 概念集部分可用） | 模型生成 + 标注「机器生成」 |
| 调用条件 | 无（来自学习记录） | 由系统记录，不生成 |

## 4. 星空：视觉与交互

| 项 | 结论 |
|---|---|
| 风格 | 深空黑底 + 发光点 + 轻微星云，保持数据可读（介于「真实天文感」与「抽象数据可视化」之间） |
| 一颗星 = | **一个词形**（多义词在词条面板内按义项分组，关系边可标注义项） |
| 亮度 | **记忆强度**（可提取性） |
| 大小 | 词频 |
| 颜色 | 情景大类 |
| 边颜色 | 关系类型（情景 / 语义 / 词根） |
| 连线策略 | **聚焦模式**：默认只画选中词的边；另有开关可整层显示 |
| 卫星星 | 关系可引出词表外词，作卫星星显示（更暗更小）；**每词最多 5 个**，其余只在面板列出；**卫星星可标记学习并进入复习** |
| 情景分区 | **两级：大类 + 子类**；清单由本项目根据六级真题话题归纳（约 10 大类 × 2-3 子类） |
| 坐标 | **情景定大区 + 词向量定位置**（GloVe 降维到 3D） |
| 交互 | 三种入口并存：① 顶部搜索跳转 ② 分层下钻（星空→星座→星）③ 侧栏列表联动高亮 |
| 检索方向 | **双向同等重要**（英→中、中→英，中文反查按义项聚组） |
| 主界面地位 | 星空是入口与全局视图；具体学习走常规列表/卡片，不强行在星空里完成 |

## 5. 词条内容：八维度

采用 byoungd《词汇篇》的八维度：**词形 / 声音 / 当前义项 / 搭配·词块 / 语法行为 / 语域与语用 / 概念与指代 / 调用条件**。

呈现方式：**分层展示**——默认展开常看的（释义、音标/发音、搭配），其余折叠；复习时只给最小提示，避免看答案。

主观维度（语法行为、语域、概念）：**模型生成并显式标注「机器生成」**，不得与有数据支撑的字段混同。

## 6. 关系模型：三层

| 层 | 数据来源 | 结构 | 视觉 |
|---|---|---|---|
| 一、同情景常用词/表达 | 六级真题话题（大类+子类）+ KyleBing 词组 | 分类树 + 共现/搭配边 | 星座内连线 |
| 二、同义 / 近义 / 反义 | WordNet + OMW 中文词网 | 带权重与方向的图 | 彩色边，近义用渐变宽度 |
| 三、词根词缀 | MorphoLex-en | 有向（词→词根/前后缀） | 跨天区长弧线 |

**三层并列，靠开关切换**，不设主从。

## 7. 学习机制

| 项 | 结论 |
|---|---|
| 机制 | **间隔规则表**（不是固定日历，也不是 FSRS） |
| 具体规则 | 阶梯 **1 / 2 / 4 / 7 / 15 / 30 天**，答对升一级，**答错退一级**；连续答对至最高级视为掌握 |
| 已掌握 | **仍以低频率出现**（防遗忘） |
| 每次复习记录 | 对/错 + **错误类型**（拼写 / 义项 / 搭配 / 听音 / 语域） |
| 错误类型的作用 | **决定下次出什么题型**：拼写错多排拼写，听音错多排听音，义项错多排辨析 |
| 练习粒度 | **每个词配一道微型题**（贴合六级考试形式，而非通用背单词题） |
| 六级题型覆盖 | 选词填空（15 选 10）、阅读中认词、听力中辨词、翻译/写作调用 |
| 一次复习出几题 | 2-3 题：词义 + 拼写 + 搭配各一 |
| 初始自评 | **60 题**，从 5,651 词里按词频分层抽样，按各档正确率回推初始掌握度 |
| 学习入口 | **自由探索导向**：先进星空随便逛；同时星空上可见到期状态 + 侧栏到期列表 + 一键开始复习 |
| 每批规模 | 每批 20 个词，做完询问是否继续 |
| 数据备份 | 支持**导出 CSV** |

## 10. 已识别风险与依赖

1. **扫描件 OCR**：CET6-Resources 含扫描图片版真题，本机暂无 OCR 工具，需安装（tesseract），失败则报告并跳过。
2. **GitHub API 限流**：未认证 60 次/小时（实测已触发 403）。绕过方式：jsdelivr `/gh/` 通道、github.com 页面解析，或使用项目所有者提供的 token。
3. **搭配数据不完整**：KyleBing `phrases` 是唯一来源，覆盖有限。
4. **主观维度需要模型生成**：语法行为/语域/概念三项无开源数据，生成内容必须标注「机器生成」。
5. **大文件下载**：GloVe 862 MB、CET6 真题 1.06 GB，首次初始化耗时较长。
6. **关系数据的映射损失**：WordNet 是英文概念集，映射到 5,651 词的中文释义会有损失；MorphoLex 覆盖约 7 万词，六级词覆盖率需实测后报告。

## 11. 验收标准

**两者都要，缺一不可：**

1. **学习闭环能跑通**：自评 → 挑选 → 练习 → 记录 → 第二天正确排出该复习的词。
2. **星空视觉成立**：500 词三层关系在星空里可看可交互，一眼看得出关系。
